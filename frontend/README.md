# AI Gym Coach: Frontend

The Next.js app users see in the browser. See the [main README](../README.md) for the full overview.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # unit tests
npm run build   # production build
```

Set `NEXT_PUBLIC_API_URL` to the backend address (defaults to `http://localhost:8000`).
